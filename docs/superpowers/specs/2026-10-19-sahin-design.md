# Sahin: design

Date: 2026-10-19. Status: approved.

## 1. What it is

Sahin is a homebrew app for a jailbroken PS5 (title ID `PPSA99404`, Home tile "Sahin") that
runs the PC version of *Blur* (Bizarre Creations, 2010) from **the user's own copy**, through
[prospero-win](https://github.com/mpereiraesaa/prospero-win) (Wine, DXVK, the PS5 Vulkan
driver). It is modelled on [nfs-blackbox-ps5](https://github.com/lavavex/nfs-blackbox-ps5)
and its launcher, both GPL-3.0, and is itself GPL-3.0.

**No copyrighted material.** The repo and the app zip hold only our own code, patches,
configuration and art, plus the open-source projects the build compiles (prospero-win, Wine,
Mesa, DXVK, the PS5 SDK). Every third-party binary the game needs is downloaded on the
console at install time and pinned by SHA-256, or taken from the user's own copy. Never
committed or bundled: a game executable, game data or diffs that produce it, Activision art,
logos or music, Microsoft redistributables (d3dx9, VC runtime), and the Amax files (they carry
no licence). The game's name appears only in the README, to say what the app works with.
All art is original and generated by a script in the repo.

Target console (the developer's): firmware 13.60, kstuff-lite, ShadowMount+ (installs apps
from `/data/homebrew`), Payload Manager with elfldr on loopback 9021, ftpsrv on 2121. No
etaHEN.

## 2. Repo layout

One repo, one history. NFS-only material is not carried over: `speed.exe`, the 1.2→1.3 diff,
EA art and music, the Xbox 360 tooling, the PS5 Options mod and the retired mods.

| Path | What |
| --- | --- |
| `tools/` | the build (`build.sh`, pinned container), prefix maker, bundle and app-zip tools, forked from nfs-blackbox-ps5 and stripped of NFS steps |
| `patches/` | the prospero-win, PS5_Mesa, PS5_Vulkan and DXVK patches, carried over unchanged (they are not game-specific) |
| `launcher/` | the forked launcher (C++20, ps5-native-app-boilerplate): paths `/data/nfs-blackbox` → `/data/sahin`, prefix `sahin`, a one-game catalog, the base-game check moved from the C++ `kManifests` table into the JSON plan, an options list instead of the single Xbox 360 option |
| `profile/blur/` | `make-blur-plan.py` (plan generator), our config files (`amax-redirect.cfg`, `dxvk.conf`), registry text, the known-good data hashes |
| `art/` | `make-art.py`, which generates the icon, the Home background and pic0 (neon streaks) |
| submodules | prospero-win, PS5_Mesa, PS5_Vulkan, PS5_PayloadSDK, ps5-native-app-boilerplate, at the commits nfs-blackbox-ps5 pins |

Upstream fixes to the NFS repos are applied by hand when they matter.

## 3. Install flow on the console

1. The user puts their Blur folder in `/data/sahin/base-games/Blur` over FTP, or on a USB
   drive as `Blur`. A USB copy is imported to the console first.
2. **Copy check** (driven by the plan's `base` section):
   - Required, case-insensitive: `Blur.exe`, `binkw32.dll`, `cache/` with its `.pak` and
     `.sig` files, `levels/`, `UI/movies/`.
   - Data files with a known hash are compared; an unknown hash is a warning on the page, not
     a refusal. Any `Blur.exe` is accepted.
3. Mod files already in the copy (`dsound.dll`, `dinput8.dll`, `d3d9.dll`, `scripts/`,
   `amax/`, `lua5.1.dll`, `discord-rpc.dll`) are left out of the install. The user's copy is
   never changed.
4. The pinned mods are placed (section 4). The prefix uses Wine's built-in `d3dx9_42`,
   `msvcr90` and `xinput1_3`. If the host run (section 6) shows a built-in is not good
   enough, the plan instead installs that DLL from the user's own `redist/` folder; never
   from a download we host.
5. The install record is written. After that the tile starts the game directly.
6. If the game exits within its first seconds, the launcher says so on its next start and
   names the likely cause: a SecuROM `Blur.exe` (the retail one), which does not run under
   Wine.

## 4. Mods

| Mod | Source, pinned by SHA-256 | Default |
| --- | --- | --- |
| Ultimate ASI Loader v9.7.4 (ThirteenAG, MIT), its `dinput8.dll` installed as `dsound.dll` | GitHub release zip `952cebfc…5c5f` | on |
| `amax-redirect.asi` (Aib0t), with an `amax-redirect.cfg` we write | GitHub release asset `dae2d6b0…9acd` | on (online) |
| Amax client 0.0.0.7: d3d9 proxy, auth, Lua plugins incl. 60 fps race cap | `cs.amax-emu.com/amax_client_files.zip` `4ee93bc7…25c7`; DXVK's d3d9 placed as `amax\dxvk.dll` | off (option) |

Not included: Discord RPC (no use on a PS5), Amax billboard ads (cosmetic), the FPS unlocker
(physics are tied to frame rate; the game stays at its cap), widescreen/FOV fixes (none exist;
the game supports 16:9), Amax's patched `Blur.exe` (Activision's file; the README says the
user's exe must run without SecuROM). `amax-redirect` patches offsets for the 1.2 exe: with
another exe online may not work, offline is unaffected.

## 5. Settings page

Holding □ while the tile starts opens Sahin's page instead of the game:

- Resolution: 3840×2160, 2560×1440, 1920×1080
- Performance overlay (DXVK HUD)
- Online through Amax: on/off
- Amax client extras: on/off
- Repair install
- Play

Settings live in `/data/sahin/settings.json` and are applied (profile, registry, ini, files)
before the game starts. Toggling a mod option re-runs the file part of the install. In game,
Options+Touchpad quits to Home (prospero-win patch 0023).

## 6. Build and verification (no console during development)

- `tools/build.sh` builds everything in the pinned container and writes
  `release/PPSA99404.zip` and `release/SHA256SUMS`. About 40 GB, a few hours clean.
- Host checks:
  - the launcher's host test suite (`tools/store-test.sh`), adapted;
  - unit tests for `make-blur-plan.py` (plan schema, every source pinned, no source without a
    URL other than our own files);
  - a **host install check**: a host tool applies the generated plan to a scratch copy of the
    developer's Blur folder and checks the result against `expect`;
  - a **copyright audit** step: the build fails if the repo or the app zip contains a PE file
    or any file not produced from the repo's sources or the pinned open-source projects.
- **Host run:** the scratch install starts under host Wine with the DXVK we build and must
  reach the main menu. That run also settles where Blur keeps resolution and controller
  settings (registry or AppData file), which the settings page writes.
- Left for the developer's console test: frame rate through the 32-bit translator, memory
  (the exe is not Large Address Aware and an unknown exe is not patched), Amax networking.

## 7. Out of scope

An in-game settings page (would need per-exe reverse engineering), Discord, achievements,
uploading or launching on the console during development, a store or catalog of other games.
